# PicPlus AI Capture — Extensão Chrome (Manifest V3)

Extensão interna para a equipe PicPlus capturar publicações do **Instagram**, **TikTok**, **YouTube** ou **sites concorrentes** (legenda/copy, fotos, vídeos e áudios) enquanto navega logada, enviando tudo para o **Estúdio de IA** analisar de forma multimodal com o Gemini.

## Como instalar no Chrome

1. Abra `chrome://extensions` no Google Chrome.
2. Ative o **Modo do desenvolvedor** (canto superior direito).
3. Clique em **Carregar sem compactação** (*Load unpacked*) e selecione esta pasta (`chrome-extension`).
4. No painel da PicPlus, acesse **Clientes → selecione o cliente → aba Pesquisa, Virais & Trends** (ou **Extensão Chrome**) e gere um **Token da Extensão** (`picext_...`).
5. Abra o ícone da extensão no Chrome, clique em **Configurar**, informe a URL da API da PicPlus e cole o token.
